# Data And Outreach Controls

This package is not a legal/compliance certification. Supported code controls include tenant-scoped suppression, stop-on-reply, unsubscribe handling, verified-contact eligibility, sender health gates, postal-address footer, encrypted credentials and bounded sends.

Before contacting real people, approve target geographies, permissible data sources, provider terms, disclosure/opt-out language and retention rules with the responsible business/privacy owner. The application does not infer permission to contact a person from a purchased email address. Do not fabricate identities, buying signals or claims about customers.

Unimplemented work includes privacy export/deletion, deletion propagation through providers/backups, consent/lawful-basis records by geography, customer terms/privacy notices and processor agreements. Define special handling for restricted sectors and sensitive data before accepting it.

Only a verified calendar-provider event represents a booking. A booked meeting is not attendance, opportunity or signed business. Reports must separate those outcomes.

Restoration must not revive previously suppressed contacts or privacy-deleted records. Reconcile post-snapshot opt-outs/deletions before re-enabling outbound. See docs/BACKUP_AND_RECOVERY.md.
